# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| latest (main) | ✅ |

## Reporting a Vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.**

Report security issues privately via GitHub's built-in mechanism:
👉 [Report a vulnerability](../../security/advisories/new)

Or email: security@docugardener.dev

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact assessment
- Any suggested remediation

## Response SLA

| Stage | Target |
|-------|--------|
| Acknowledgement | 48 hours |
| Initial assessment | 5 business days |
| Fix or mitigation | 30 days for critical, 90 days for others |
| Public disclosure | Coordinated with reporter after fix is deployed |

## Scope

In scope: the DocuGardener application, API endpoints, authentication flows, webhook handling, and data handling.

Out of scope: third-party dependencies (report upstream), GitHub infrastructure, issues requiring physical access.
